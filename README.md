# O Que Vamos Assistir Hoje?

Plataforma web para recomendação de filmes e séries, desenvolvida para auxiliar usuários na descoberta de conteúdos de entretenimento com base em preferências, categorias e interesses.

## Objetivo

O objetivo do sistema é oferecer uma experiência simples e organizada para que usuários possam encontrar sugestões de filmes e séries de acordo com seus interesses, facilitando a escolha do que assistir.

## Visão Geral da Solução

A aplicação é composta por um frontend web em React, uma API backend em Spring Boot e uma futura integração com banco de dados PostgreSQL para persistência das informações.
