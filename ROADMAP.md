# Roadmap do Projeto

Este roadmap apresenta a evolução planejada da plataforma O Que Vamos Assistir Hoje?, organizada em sprints incrementais.

## Sprint 1 - Foundation

Objetivo: criar a base técnica inicial do projeto.

### Entregas

- Estrutura inicial do repositório
- Configuração do Git e GitHub
- Frontend React criado com Vite
- Backend Spring Boot criado
- Health check da API validado com Spring Boot Actuator
- README inicial do projeto

### Status

Concluída parcialmente.

---

## Sprint 2 - Autenticação e Usuários

Objetivo: implementar a base de usuários e autenticação.

### Entregas planejadas

- Modelagem da entidade de usuário
- Cadastro de usuários
- Login
- Estrutura inicial de autenticação
- Preparação para integração com banco de dados

---

## Sprint 3 - Catálogo de Filmes e Séries

Objetivo: criar a base funcional do catálogo de conteúdos.

### Entregas planejadas

- Modelagem de filmes e séries
- Cadastro de conteúdos
- Listagem de conteúdos
- Pesquisa por título
- Filtro por gênero

---

## Sprint 4 - Favoritos e Recomendações

Objetivo: permitir que usuários salvem preferências e recebam sugestões.

### Entregas planejadas

- Lista de favoritos
- Preferências do usuário
- Recomendações simples baseadas em gênero
- Integração entre frontend e backend

---

## Sprint 5 - Infraestrutura Local e Containerização

Objetivo: preparar o ambiente local com foco em DevOps.

### Entregas planejadas

- Dockerfile do frontend
- Dockerfile do backend
- Docker Compose com frontend, backend e PostgreSQL
- Reativação da integração com PostgreSQL
- Validação local com containers

---

## Sprint 6 - Deploy em Nuvem

Objetivo: publicar o MVP em ambiente de nuvem.

### Entregas planejadas

- Definição da cloud
- Provisionamento de ambiente
- Deploy do backend
- Deploy do frontend
- Banco de dados em nuvem
- Documentação de release

---

## Evoluções Futuras

- Notificações de novos lançamentos
- Recomendações por humor ou faixa etária
- Integração com API externa de filmes e séries
- Pipeline de CI/CD
- Observabilidade com logs e métricas
- Testes automatizados
